# Popup Configuration

[Back to configuration](../config.md)

Tooltip and popup styling.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `popup.opacity` | Background opacity (0-1) | `1` | number [0, 1] |
| `popup.leftPadding` | Left padding inside popup | `10` | number [0, 100] |
| `popup.rightPadding` | Right padding inside popup | `10` | number [0, 100] |
| `popup.upPadding` | Top padding inside popup | `10` | number [0, 100] |
| `popup.downPadding` | Bottom padding inside popup | `10` | number [0, 100] |
| `popup.margin` | Margin around popup | `40` | number [0, 100] |
| `popup.maxWidth` | Maximum width before text wraps | `175` | number [0, 300] |
| `popup.shape` | Visual style of popup | `"boxWithArrow"` | 'box' \| 'boxWithArrow' |
| `popup.activation` | When popup appears | `"onHover"` | 'onHover' \| 'onFocus' \| 'onSelect' |
| `popup.borderRadius` | Corner radius for rounded popups | `5` | number [0, 20] |
| `popup.backgroundColor` | Background color scheme | `"dark"` | 'dark' \| 'light' |
| `popup.isShowCrosshair` | Show crosshair | `true` | boolean |
| `popup.isCrosshairFollowPointer` | Make crosshair follow pointer | `false` | boolean |
