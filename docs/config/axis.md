# Axis Configuration

[Back to configuration](../config.md)

Axis display, labels, ticks, and positioning.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `axis.horiz.isDrawAxis` | Enable drawing this axis | `true` | boolean |
| `axis.horiz.position` | Position relative to chart | `"south"` | 'north' \| 'south' |
| `axis.horiz.labelOrder` | Order of label values along axis | `"westToEast"` | 'westToEast' \| 'eastToWest' |
| `axis.horiz.isStaggerLabels` | Stagger labels to prevent overlap | `false` | boolean |
| `axis.horiz.isWrapLabels` | Wrap long labels to multiple lines | `true` | boolean |
| `axis.horiz.line.isDrawAxisLine` | Draw the main axis line | `true` | boolean |
| `axis.horiz.line.isDrawOverhang` | Draw overhang beyond data range | `true` | boolean |
| `axis.horiz.line.strokeWidth` | Width of axis line stroke | `2` | number |
| `axis.horiz.line.strokeLinecap` | End cap style for axis line | `"round"` | string |
| `axis.horiz.ticks.isDrawTicks` | Enable drawing of tick marks | `true` | boolean |
| `axis.horiz.ticks.padding` | Padding around tick marks | `3` | number |
| `axis.horiz.ticks.opacity` | Opacity of tick marks (0-1) | `1` | number |
| `axis.horiz.ticks.strokeWidth` | Width of tick mark lines | `2` | number |
| `axis.horiz.ticks.strokeLinecap` | End cap style for tick lines | `"round"` | string |
| `axis.horiz.ticks.length` | Length of tick marks in pixels | `10` | number |
| `axis.horiz.ticks.labelFormat` | Format for tick labels | `"raw"` | string |
| `axis.horiz.ticks.step` | Interval between tick marks | `1` | number |
| `axis.horiz.ticks.isOnDatapoint` | Whether ticks align with data points (bar charts only) | `true` | boolean |
| `axis.horiz.ticks.labels.isDrawTickLabels` | Draw labels on tick marks | `true` | boolean |
| `axis.horiz.ticks.labels.fontSize` | Font size for tick labels | `"10pt"` | string |
| `axis.horiz.ticks.labels.angle` | Rotation angle for labels in degrees | `0` | number |
| `axis.horiz.ticks.labels.offsetGap` | Offset distance from tick marks | `4` | number |
| `axis.horiz.ticks.labels.gap` | Gap between adjacent labels | `10` | number |
| `axis.horiz.title.isDrawTitle` | Draw axis title | `false` | boolean |
| `axis.horiz.title.text` | Title text content | `""` | string |
| `axis.horiz.title.gap` | Gap between title and axis | `8` | number |
| `axis.horiz.title.fontSize` | Font size for title | `"12pt"` | string |
| `axis.horiz.title.align` | Text alignment relative to axis | `"middle"` | 'start' \| 'middle' \| 'end' |
| `axis.vert.isDrawAxis` | Enable drawing this axis | `true` | boolean |
| `axis.vert.position` | Position relative to chart | `"west"` | 'east' \| 'west' |
| `axis.vert.labelOrder` | Order of label values along axis | `"southToNorth"` | 'southToNorth' \| 'northToSouth' |
| `axis.vert.isStaggerLabels` | Stagger labels to prevent overlap | `false` | boolean |
| `axis.vert.isWrapLabels` | Wrap long labels onto multiple lines | `false` | boolean |
| `axis.vert.line.isDrawAxisLine` | Draw the main axis line | `true` | boolean |
| `axis.vert.line.isDrawOverhang` | Draw overhang beyond data range | `true` | boolean |
| `axis.vert.line.strokeWidth` | Width of axis line stroke | `2` | number |
| `axis.vert.line.strokeLinecap` | End cap style for axis line | `"round"` | string |
| `axis.vert.ticks.isDrawTicks` | Enable drawing of tick marks | `true` | boolean |
| `axis.vert.ticks.padding` | Padding around tick marks | `3` | number |
| `axis.vert.ticks.opacity` | Opacity of tick marks (0-1) | `1` | number |
| `axis.vert.ticks.strokeWidth` | Width of tick mark lines | `2` | number |
| `axis.vert.ticks.strokeLinecap` | End cap style for tick lines | `"round"` | string |
| `axis.vert.ticks.length` | Length of tick marks in pixels | `10` | number |
| `axis.vert.ticks.labelFormat` | Format for tick labels | `"raw"` | string |
| `axis.vert.ticks.step` | Interval between tick marks | `1` | number |
| `axis.vert.ticks.isOnDatapoint` | Whether ticks align with data points (bar charts only) | `true` | boolean |
