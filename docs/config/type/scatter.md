# Scatter Type Configuration

[Back to chart-type configuration](../type.md)

Scatter plot settings.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `type.scatter.minYValue` | Minimum Y value override | `"unset"` | number \| 'unset' |
| `type.scatter.maxYValue` | Maximum Y value override | `"unset"` | number \| 'unset' |
| `type.scatter.isShowTrendLine` | Draw trend/regression line | `false` | boolean |
| `type.scatter.isShowOutliers` | Highlight statistical outliers | `false` | boolean |
