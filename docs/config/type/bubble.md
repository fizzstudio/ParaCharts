# Bubble Type Configuration

[Back to chart-type configuration](../type.md)

Shared settings for Cartesian chart types.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `type.bubble.minYValue` | Minimum Y value override | `"unset"` | number \| 'unset' |
| `type.bubble.maxYValue` | Maximum Y value override | `"unset"` | number \| 'unset' |
| `type.bubble.xFacet` | Facet to display on the X axis | `""` | string |
| `type.bubble.yFacet` | Facet to display on the Y axis | `""` | string |
| `type.bubble.bubbleFacet` | Facet to use for bubble size | `""` | string |
| `type.bubble.labelFacet` | Facet to use for as labels | `""` | string |
| `type.bubble.maxBubbleSize` | Max bubble size | `3` | number [1.1, 8] |
| `type.bubble.minBubbleSize` | Min bubble size | `0.5` | number [0.1, 0.9] |
