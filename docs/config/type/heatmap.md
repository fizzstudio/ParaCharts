# Heatmap Type Configuration

[Back to chart-type configuration](../type.md)

Heat map settings.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `type.heatmap.minYValue` | Minimum Y value override | `"unset"` | number \| 'unset' |
| `type.heatmap.maxYValue` | Maximum Y value override | `"unset"` | number \| 'unset' |
| `type.heatmap.resolution` | Grid resolution for heat map | `20` | number [5, 100] |
| `type.heatmap.xFacet` | Axis to group on the X axis | `""` | string |
| `type.heatmap.yFacet` | Axis to group on the Y axis | `""` | string |
