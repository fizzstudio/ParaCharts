# Venn Type Configuration

[Back to chart-type configuration](../type.md)

Venn diagram settings.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `type.venn.orientationAngleOffset` | Rotation offset for diagram orientation | `0` | number [0, 360] |
| `type.venn.explode` | Which circles to separate/explode | `""` | string |
| `type.venn.insideLabels.contents` | Content to display in inside labels | `""` | string |
| `type.venn.outsideLabels.contents` | Content to display in outside labels | `""` | string |
