# Histogram Type Configuration

[Back to chart-type configuration](../type.md)

Histogram settings.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `type.histogram.minYValue` | Minimum Y value override | `"unset"` | number \| 'unset' |
| `type.histogram.maxYValue` | Maximum Y value override | `"unset"` | number \| 'unset' |
| `type.histogram.bins` | Number of bins for grouping data | `20` | number [5, 100] |
| `type.histogram.displayAxis` | Which axis shows the histogram bars | `"x"` | string |
| `type.histogram.groupingFacet` | Which axis is used for grouping | `""` | string |
| `type.histogram.relativeAxes` | Show counts or percentages | `"Counts"` | 'Counts' \| 'Percentage' |
