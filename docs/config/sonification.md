# Sonification Configuration

[Back to configuration](../config.md)

Audio feedback and sonification settings.

Settings marked with † are advanced.

| Setting Path | Description | Default | Type |
|---|---|---|---|
| `sonification.isSonificationEnabled` | Enable sonification audio feedback | `false` | boolean |
| `sonification.isRiffEnabled` | Enable series riff playback | `true` | boolean |
| `sonification.isNotificationEnabled` | Enable audio notifications | `true` | boolean |
| `sonification.hertzLower` | Lower frequency bound in Hz | `35` | number [0, 107] |
| `sonification.hertzUpper` | Upper frequency bound in Hz | `96` | number [0, 107] |
| `sonification.riffSpeedIndex` | Speed for musical riffs | `2` | number [0, 4] |
| `sonification.isArpeggiateChords` | Play chords as arpeggios | `true` | boolean |
