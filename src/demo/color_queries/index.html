Testing with DevTools

  1. Open DevTools → Rendering tab (⋮ → More tools → Rendering)
  2. Set Emulate CSS media feature prefers-color-scheme to dark — chart should switch when Theme is "System"
  3. Set prefers-contrast to more — contrastLevel should jump to 2.0 when Contrast is "System"
  4. Set forced-colors to active — series retain author colors (pattern/shape redundancy); axes use system CanvasText color
  5. Pick an explicit Theme (e.g. Light), then switch the system to dark — chart stays light; source shows user
  6. Reload the page — stored preferences restore (check the localStorage panel above)
  7. Click Clear stored preferences, then reload — chart returns to system defaults
